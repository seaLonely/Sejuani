## 2. system prompt 接线（改动 `src/core/agent/brain.ts`）

### 2.1 注入「可用技能」段
- `buildSystemPrompt` 增加：调 `listSkills()`，若非空，注入一段（预算 ≤1500 字符，超出按 savedAt 倒序截断）：
  ```
  【可用技能】优先复用（用 skill_run 执行；不存在合适技能再自行处理）：
  - <name>(<kind>): <description>
  ```
- 位置：在能力模块说明之后、项目上下文/长期记忆之前。
- 引导语补一条（编号顺延）：「接到任务先用 skill_list 看有无可复用技能；完成可复用的多步流程后，可建议用 skill_save 固化」。

### 2.2 子代理/agent.task 的处理
- 子代理（subagentDepth≥1）默认白名单为只读，不含 skill_run/skill_save，「可用技能」段仍可注入（只读参考无害）；是否注入可视 token 预算决定，缺省注入。
